## 🧠 Tentang Saya

Saya adalah **solo developer** yang memanfaatkan **AI assistant** sebagai partner kerja sehari-hari. Kombinasi ini memungkinkan saya bergerak cepat, dari riset, desain, hingga deploy, tanpa kehilangan kendali atas kualitas kode.

> **Prinsip saya:** AI bukan pengganti, tapi *force multiplier*. Saya yang memutuskan arsitektur, AI yang mempercepat eksekusi.

| Peran | Fokus |
| :--- | :--- |
| 🧑‍💻 **Saya** | Produk, arsitektur, logika bisnis, review & kualitas |
| 🤖 **AI Assistant** | Scaffolding, debugging, test, dokumentasi, refactoring |
| ⚡ **Hasil** | Iterasi cepat, konsisten, dan tetap maintainable |
